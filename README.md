## 💡 How to Generate the PDF Manually

You can easily generate the PDF yourself using the HTML file:

### Method 1: Using Your Browser (Recommended)

1. **Open the HTML file** in your browser:
   ```bash
   # On Linux/Mac
   xdg-open ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.html
   
   # Or simply double-click the file
   ```

2. **Print to PDF:**
   - **Windows/Linux:** Press `Ctrl+P`
   - **Mac:** Press `Cmd+P`
   - **Chrome/Edge:** Choose "Save as PDF" as the destination
   - **Firefox:** Choose "Microsoft Print to PDF" or "Save as PDF"
   - Click **Save**

3. **Save the file** as `ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.pdf`

### Method 2: Using Command Line (If You Have Tools Installed)

If you have `pandoc` installed:
```bash
pandoc ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.md -o ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.pdf
```

If you have `wkhtmltopdf` installed:
```bash
wkhtmltopdf ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.html ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.pdf
```

If you have `weasyprint` installed:
```bash
weasyprint ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.html ULTIMATE_MARRIAGE_GUIDE_Parts_1-3.pdf
```
